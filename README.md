# Баннер-бот Seraphic Aurora

Рисует счётчики участников и войса прямо на баннере Discord-сервера
и перезаливает его через API. Работает сам, вмешательство не требуется.

Демонстрация и настройка внешнего вида: **https://zelonka228.github.io/seraphic-counters/**

---

## Как это работает

Бот не висит в памяти постоянно. Раз в 10 минут его будят, он считает статистику,
перерисовывает баннер и выключается. Секунды работы вместо круглосуточного процесса.

```
cron-job.org  ──каждые 10 минут──►  GitHub Actions  ──►  once.js  ──►  баннер сервера
                                          │
                                          ├──►  карточка состояния в Discord
                                          └──►  пинг сторожу healthchecks.io
```

**Почему будильник внешний.** Расписание внутри GitHub (`cron` в `banner.yml`)
для этого аккаунта не срабатывает — ни разу за несколько часов при полностью
верных настройках. Аккаунт под торговыми ограничениями GitHub, и это, вероятно,
задевает не только приватные репозитории. Файл расписания оставлен как запасной:
если у GitHub однажды заработает, лишних заливок не будет — их режут кулдаун и потолок.

---

## Куда смотреть, если что-то не так

**1. Карточка в Discord.** Бот переписывает одно и то же сообщение в канале
оповещений после каждой проверки. Смотри на поле «Последняя проверка»:
свежее время — всё хорошо, застывшее — бот молчит.

**2. Письмо от сторожа.** healthchecks.io ждёт пинг каждые 20 минут с запасом
в 10. Пропало два подряд — приходит письмо. Это единственное, что ловит
полное молчание: если бот вообще не запустился, жаловаться некому.

**3. Вкладка Actions.** Зелёная галочка — прогон отработал, красный крестик —
упал, внутри написано почему. Там же кнопка **Run workflow** для запуска вручную,
с галочкой холостого прогона (посчитает и нарисует, но на сервер не отправит).

**4. cron-job.org.** Статус срабатывания должен быть `204`. Другой код означает,
что будильник не достучался до GitHub — чаще всего истёк или потерял права токен.

## Настройка внешнего вида

Открой [сайт](https://zelonka228.github.io/seraphic-counters/), покрути ползунки,
нажми «Скопировать настройки» и вставь полученный блок в `config.json`
вместо `banner.badges` и `banner.style`. Запушь — обновится в течение 10 минут.

Правку оформления бот замечает даже при неизменных цифрах: в отпечаток входит
и стиль тоже.

| Поле | Что делает |
|---|---|
| `badges[].counter` | `members`, `online`, `voice`, `boosts` |
| `badges[].icon` | `mic`, `users`, `boost` |
| `badges[].prefix` | текст перед числом, например `"Онлайн: "` |
| `style.direction` | `column` — в столбик, `row` — в линию |
| `style.x` / `style.y` | левый верхний угол первой плашки, холст 960×540 |
| `voice.excludeBots` | не считать ботов, сидящих в войсе |
| `voice.excludeAfk` | не считать ушедших в AFK-канал |

Подложка — `assets/banner-base.png`, 960×540. Шрифт цифр — `assets/font.ttf`,
он вложен в репозиторий, иначе на Linux рендер выглядел бы иначе, чем на Windows.

## Команды

```bash
npm test        # проверка рендера и логики, без подключения к Discord
npm run check   # подключиться, показать права и живые цифры, ничего не менять
npm run preview # нарисовать preview.png с выдуманными цифрами
npm run banner  # постоянный процесс (для своей машины, под pm2)
npm start       # второй режим: счётчики в названиях каналов
```

Отправить сообщение через вебхук вручную:

```bash
node alert.js "Заголовок" "Текст" success
```

Цвета: `success` зелёный, `info` синий, `warn` жёлтый, `error` красный.
То же самое кнопкой — прогон «Отправить сообщение» на вкладке Actions.

## Лимиты Discord

Четыре независимых рубежа, чтобы никогда в них не упереться:

1. **Цифры не изменились — запроса нет вообще.** Ночью бот молчит часами.
2. **Кулдаун 9 минут.** Меньше интервала будильника специально: при совпадении
   каждый второй запуск отказывал бы и баннер отставал бы вдвое.
3. **Потолок 8 заливок в час.** Жёсткий, по журналу в `.state.json`,
   переживает перезапуск. Выше частоты будильника, чтобы не резать законные обновления.
4. **Сигнал самого Discord.** Если он придержит запрос, бот возьмёт названное
   им время и продлит паузу ровно на столько.

Реально уходит до 6 заливок в час. Блокировка у Discord наступает при 10 000
отклонённых запросов за 10 минут — разница в четыре порядка.

## Безопасность

Репозиторий публичный вынужденно: аккаунт под торговыми ограничениями,
приватные создавать нельзя. Поэтому важно, что именно в нём лежит.

**Чего в репозитории нет и не должно быть.** Токен бота, ID сервера, ссылка
вебхука и пинг сторожа хранятся в зашифрованных секретах GitHub. В коде их нет,
в логи они не попадают, форкам недоступны. История коммитов проверена — чисто.

**Что сделано для защиты:**

- Права прогонов урезаны до `contents: read` — читать репозиторий и только.
  Исключение — продление расписания, ему нужна запись.
- Сторонние действия закреплены **по хешу коммита**, а не по тегу.
  Тег можно переставить на другой код, хеш — нет. Это защита от подмены
  действия, у которого есть доступ к секретам.
- `dependabot.yml` раз в месяц обновляет закреплённые хеши и зависимости,
  чтобы закрепление не превратилось в застой без исправлений безопасности.
- Токен для продления — тонкой настройки, ограничен одним репозиторием
  и четырьмя правами.

**Что зависит от тебя:**

- Включить двухфакторную аутентификацию на GitHub и на cron-job.org.
  В обоих аккаунтах лежат ключи от бота.
- Не давать никому доступ к репозиторию. Сейчас доступ у одного тебя.
- Если токен или вебхук где-то засветились — пересоздать. Вебхук в настройках
  канала, токен бота в Developer Portal, дальше обновить секрет в репозитории.
- Токены с истечением срока однажды перестанут работать молча. Сторож это
  заметит: пинги прекратятся, придёт письмо.

## Если понадобится перенести

`banner.js` умеет работать постоянным процессом — на своей машине или на сервере:

```bash
npm i -g pm2
pm2 start banner.js --name banner && pm2 save && pm2 startup
```

pm2 сам поднимет его после падения и после перезагрузки. Реакция быстрее:
опрос каждые 30 секунд вместо 10 минут. Минус — пока машина выключена,
цифры замирают.
